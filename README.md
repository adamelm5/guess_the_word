# guess_the_word

## Description

This is a simple program for the game "Guess the word".

The program is written in C.

## Usage

To compile the program and run it, type:

```bash
make
```

You can also run the game after compiling it:

```bash
./guess_the_word
```

To clean the project, type:

```bash
make clean
```

## Report

A report is available [here](report.pdf) in french.

The program will ask you to chose between animals, countries and cities, Then it will show you few random letters and you have to guess the word.
